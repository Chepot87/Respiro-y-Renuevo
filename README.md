# Respiro y Renuevo

Primera base local de la página Experiencias Privadas, en HTML, CSS y JavaScript sin dependencias.

Abre `index.html` en un navegador o utiliza Live Server desde VS Code.

## Archivos
- `index.html`: estructura y contenido bilingüe.
- `styles.css`: colores, tipografía, diseño y adaptación móvil.
- `script.js`: menú móvil y aviso del formulario de demostración.
- `assets/`: logo, fotografía y fuentes descargados del sitio actual.
- `reference.html`: captura del HTML original para consultar la referencia.

## Páginas propias
- `index.html`: Inicio.
- `retiros-y-eventos.html`: Retiros y eventos.
- `experiencias-privadas.html`: Experiencias privadas (la página que trabajamos primero).
- `nosotros.html`: Historia, valores y fundadora.
- `contacto.html`: Contacto.
- `terminos.html`, `privacidad.html`, `accesibilidad.html`: información de esta vista previa; condiciones de reserva pendientes.

Todos los enlaces del header y los enlaces internos del footer permanecen en este proyecto. Solo las redes sociales llevan a servicios externos. El idioma elegido se conserva al navegar. No se muestran fechas ni reservas de eventos sin confirmar.

Esta base reproduce identidad y contenido; todavía no es una réplica exacta píxel por píxel. Algunos textos usan fuentes de respaldo. Confirmar las licencias de las fuentes antes de publicar. El formulario no tiene backend y no envía datos. El widget Wix no se incluye.
