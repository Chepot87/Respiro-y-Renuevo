# Respiro y Renuevo

Primera base local de la página Experiencias Privadas, en HTML, CSS y JavaScript sin dependencias.

Abre `index.html` en un navegador o utiliza Live Server desde VS Code.

## Archivos
- `index.html`: estructura y contenido bilingüe.
- `styles.css`: colores, tipografía, diseño y adaptación móvil.
- `script.js`: menú móvil y aviso del formulario de demostración.
- `assets/`: logo, fotografía y fuentes descargados del sitio actual.
- `reference.html`: captura del HTML original para consultar la referencia.
